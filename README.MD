# COinv

**Advanced auditing for Minecraft servers, built to extend CoreProtect.**

COinv is a planned CoreProtect add-on designed to provide additional logging and investigation tools for activity that CoreProtect doesn't adequately cover.

## Features

- **Advanced Inventory Auditing** — Track inventory changes, inventory editing, item transfers, and other inventory-related activity not adequately covered by CoreProtect.
- **Ender Chest Auditing** — Additional tracking for ender chest access and modifications.
- **Staff Activity Logging** — Audit relevant administrator and staff actions.
- **Item Auditing** — Track item creation, modification, removal, and suspicious item manipulation where technically detectable.
- **Player Data Tracking** — Additional auditing for changes to player data, including experience, levels, game modes, and effects.
- **Command Auditing** — Record relevant commands and administrative actions.
- **Plugin Activity Tracking** — Capture additional changes caused by other plugins where technically possible.
- **Player Investigation Tools** — Search and investigate player activity through dedicated commands.
- **Inventory History** — Review recorded inventory changes and historical information.
- **Investigation GUI** — Browse and inspect records through an intuitive in-game interface.
- **Search and Filtering** — Find relevant records by player, action, time, and other available criteria.
- **CoreProtect Integration** — Work alongside CoreProtect without replacing or interfering with its existing functionality.
- **Duplicate Prevention** — Avoid unnecessarily duplicating events CoreProtect already logs adequately.
- **Performance-Focused Logging** — Designed with asynchronous database operations and efficient data handling.
- **Configurable Retention** — Configure how long COinv's additional records are retained.
- **Permissions** — Control access to auditing, investigation, and administrative commands.
- **Extensible Design** — Built with future integrations and additional auditing features in mind.
